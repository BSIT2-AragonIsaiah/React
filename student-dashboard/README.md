1. What is a React component?

A React component is a building block of a React application that controls a specific area or feature in the application. For instance, a header part, student profile, course list, or counter can be a component. In general, components make the application modular instead of having all the code mixed in one file.

2. What is the difference between props and state?

Props are values passed from one component to another. They carry information coming from parent components to child components. On the other hand, state is the information held by a component. In the activity, the Props carry the student’s data such as student name, program, and year. State was used in the counter to update the number of activities performed.

3. What event does your counter use?

The counter uses a click event. The counter increments when the + button is clicked and decrements when the − button is clicked. The counter value changes upon clicking either of the two buttons.

4. Which components did you create?

The components created include Header, Student Profile, Course List, Course, Activity Counter, and Footer. The App component was also created to hold all the other components.

5. How are your components composed?

The components are composed by embedding some components within other components. For instance, the App component holds the Header, Student Profile, Course List, Activity Counter, and Footer components. Similarly, the Course List component contains the Course components. This way, the App component is the main component in the application.

6. What was the most challenging part of the activity?

The most challenging part of this activity was comprehending how the components worked together. I had to understand how data was transferred between components using Props and how state was used to update the number of activities in the counter. However, once I understood how the components, props, and state worked together, everything else became straightforward.
