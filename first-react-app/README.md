# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

1. What is React?

React is a JavaScript library used to build user interfaces and web applications using reusable components.

2. What is a component?

A component is a reusable building block of a React application that contains the UI and its behavior.

3. What are props?

Props are data passed from one component to another. They allow a component to be reused with different information.

4. What is state?

State is data that can change within a component. When the state changes, React updates the user interface.

5. What event did you implement?

I implemented the onClick event for the Activity Counter. It is used when the user clicks the Complete Activity button, which increases the completed activities count.

6. How did you compose your components?

I composed my components by breaking the application into smaller, reusable components. Each component was responsible for a specific part of the interface, and I combined them together to create the complete application.

7. What problem did you encounter during installation/development?

The problem I encountered during installation/development was setting up React development environment and ensuring that all tools and dependencies were properly set up. Furthermore, I encountered some errors while trying to run the project.

8.  How did you solve it?

I solved the problem by looking at the error messages, checking the installation process and making sure that all the necessary components were correctly installed and set up. I also re-run some commands and test the application multiple times until the errors disappeared.
